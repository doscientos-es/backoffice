# Doscientos Backoffice

Aplicación de gestión comercial y operativa de Doscientos, con áreas de proyectos, presupuestos, facturación y tareas.

## Tecnología

El proyecto utiliza Next.js, React y Supabase.

## Desarrollo

Requiere Node.js 22 y pnpm.

- Instalar dependencias: pnpm install
- Iniciar el entorno local: pnpm dev
- Ejecutar pruebas: pnpm test
